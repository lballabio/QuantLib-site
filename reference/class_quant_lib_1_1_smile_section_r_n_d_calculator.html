Detailed Description

Tabulates log-moneyness against the normal quantile \( z = \Phi^{-1}(P(S \leq K)) \), which is linear for a lognormal law and stays well conditioned in the wings.

Parameters
nStdhalf-width of the tabulated range in normal quantiles, or the deepest the smile still prices. invcdf saturates there.
