Detailed Description

Generic constant-notional cross currency swap.

The notional amounts are constant and exchanged at inception and maturity.

The first leg holds the pay currency cashflows and second leg holds the receive currency cashflows.

Constructs a cross-currency swap with multiple legs and their respective currencies.

Initializes a cross-currency swap with an arbitrary number of legs, each specified by a sequence of cash flows (Leg) and associated with its own currency. The payer vector determines the direction of each leg (payer or receiver).

Parameters
legsA vector of cash flow sequences, one for each leg of the swap.
payerA vector of booleans indicating the direction of each leg: true for payer, false for receiver.
currenciesA vector of currencies, one for each leg, specifying the currency in which the corresponding leg's cash flows are denominated.
Note
The sizes of the legs, payer, and currencies vectors must all be equal.
Warning
The notional amounts, payment schedules, and other details of each leg must be set up in the provided Leg objects before constructing the swap.
