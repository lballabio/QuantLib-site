Detailed Description

Limited-memory BFGS for bound-constrained optimization (L-BFGS-B).

Faithful implementation of the algorithm of Byrd, Lu, Nocedal and Zhu, "A Limited Memory Algorithm for Bound Constrained Optimization", SIAM J. Sci. Comput. 16(5):1190-1208, 1995.

Coordinates whose bound is \( \pm \mathrm{DBL\_MAX} \) are treated as unbounded, so with no active bounds the method reduces to plain limited-memory BFGS. Explicit bounds may instead be passed to the constructor, overriding the constraint.

Limited memory trades accuracy of the Hessian model for cost: it stores only the last memory correction pairs, needing \( O(\mathrm{memory}\cdot n) \) storage and work per step instead of the \( O(n^2) \) of dense BFGS, at the price of linear rather than superlinear convergence. This typically results in a modest increase in iteration count.
