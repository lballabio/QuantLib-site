Detailed Description

Index selection for irregular Ibor coupons.

A default constructor is empty, meaning that broken periods fix on the leg's own index as usual. A non-empty one supplies the candidate indices used instead.

The indices are supplied as fully constructed objects so that each one can use its own conventions, fixing history and forwarding curve.

For ClosestIndex, the index whose maturity is closest to the coupon end date is used. For Interpolated, the two index maturities bracketing the coupon end date are used for linear interpolation in calendar days.

The weights depend on the accrual dates.
