Detailed Description

template<class Model>
struct QuantLib::XabrModelTraits< Model >

Traits class for XABR model customization points.

This traits class provides default implementations for model operations used by XabrSwaptionVolatilityCube. The defaults assume a 4-parameter SABR-like model with the standard SABRInterpolation constructor signature.

Custom models can specialize this template to override:

  • nParams: number of model parameters (default: 4)
  • createInterpolation: factory for smile interpolation
  • extractGamma: extract gamma parameter (default: 0)
  • createSmileSection: factory for smile sections
Note
The primary template works for any model whose Interpolation type accepts the same constructor signature as SABRInterpolation (4 params, shift, volatilityType). Models with different constructors (e.g., NoArbSabr, ZABR) should specialize this traits class.
