Detailed Description

Black-volatility term structure.

This abstract class defines the interface of concrete Black-volatility term structures which will be derived from this one.

Volatilities are assumed to be expressed on an annual basis.

Instances are expected to be held by shared_ptr; the default smileSectionImpl() adapter uses shared_from_this() to keep the surface alive for as long as the returned SmileSection.

Smile section calculation. The default implementation wraps the vol surface into a SmileSection adapter that holds a shared_ptr to *this (via shared_from_this()), so the surface stays alive for the lifetime of the returned section. Derived classes with a native smile representation can override to return self-contained objects.
